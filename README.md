# Bitset

Динамический битовый массив на C++20 с компактным хранением в 64-битных словах.

## Что реализовано

- Создание массива по размеру, строке из битов, диапазону итераторов или представлению; копирование и присваивание.
- Чтение и изменение отдельных битов через прокси-ссылки, итераторы произвольного доступа.
- Побитовые операции `&`, `|`, `^`, `~`, установка, сброс и инверсия битов.
- Сдвиги: `<<` дописывает нули справа, увеличивая размер, а `>>` удаляет биты справа.
- Проверки `all()` и `any()`, подсчёт единиц через `count()`, сравнение и строковый вывод.
- Изменяемые и константные представления участков (`subview`) без копирования данных.

## Быстрый старт

Из корня проекта создайте `main.cpp`:

```cpp
#include "bitset.h"
#include <iostream>

int main() {
    bitset bits("10110");
    bits[1] = true;
    auto part = bits.subview(2, 3);
    part.flip();

    std::cout << bits << '\n';         // 11001
    std::cout << bits.count() << '\n'; // 3
}
```

Скомпилироавть и запустить (GCC, Linux):

```sh
g++ -std=c++20 -Wall -Wextra -Isrc main.cpp src/bitset.cpp -o bitset-demo
./bitset-demo
```

Для запуска тестов необходимо установить Catch2 v3 с библиотекой `Catch2Main` и выполнить:

```sh
g++ -std=c++20 -Isrc src/bitset.cpp test/*.cpp -lCatch2Main -lCatch2 -o bitset-tests
./bitset-tests
```
